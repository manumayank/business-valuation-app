TROUBLESHOOTING QUICK FIXES:

Issue: Port 5000 already in use
  → Kill: lsof -i :5000 | grep LISTEN | awk '{print $2}' | xargs kill -9

Issue: Port 3000 already in use
  → Kill: lsof -i :3000 | grep LISTEN | awk '{print $2}' | xargs kill -9

Issue: Backend server is not running
  → Check Terminal 1 is running: npm start

Issue: Migrations didn't run
  → Delete valuation.db and restart backend

Issue: LocalStorage not showing tokens
  → Open DevTools F12 → Application tab → Local Storage on left

Issue: Can't login after registration
  → Make sure password is exactly: TestPass123!
  → Check backend logs for errors
