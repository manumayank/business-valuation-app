✅ PRD SECTION — VAC ENGINE CALCULATION SPECIFICATION
1. Overview

The Value Acceleration Calculator (VAC) computes:

Risk Score

Normalized Earnings & EBITDA

EBITDA Multiple (custom/common/industry/risk-adjusted)

Current Valuation

Value Acceleration Uplift across:

Size Increase

Efficiency Increase

Multiple Increase (Risk
Reduction)

Probability-weighted valuation distribution

Wealth Gap projection

All formulas below must be implemented exactly to match Excel behavior.

2. Input Definitions

4. STEP 2 — EARNINGS ANALYSIS

Inputs:

revenue
pretaxProfit
depreciation
interest
discretionarySpending
ownerSalaryAdj
rentAdj


Baseline margins (fixed):

Revenue margin: 1
Pre-tax margin: 0.075
Depreciation: 0.01
Interest: 0.01
Discretionary Spending: 0.02

Baseline Values
baselineRevenue = revenue * 1
baselinePretax = revenue * 0.075
baselineDep = revenue * 0.01
baselineInterest = revenue * 0.01
baselineDiscretionary = revenue * 0.02

EBITDA CALCULATION

Excel logic:

IF(ISBLANK(H30),
    baselineRevenue + baselinePretax + baselineDep + baselineInterest + discretionary,
    pretaxProfit + depreciation + interest + discretionary
)


Backend formula:

if fromFinancialsMissing:
    EBITDA = baselinePretax + baselineDep + baselineInterest + discretionarySpending
else:
    EBITDA = pretaxProfit + depreciation + interest + discretionarySpending

EBITDA Margin
if revenue == 0 → 0
else EBITDA / revenue

6. CURRENT ENTERPRISE VALUE
currentValue = EBITDA * multipleUsed

7. VALUE ACCELERATION CALCULATIONS

VAC has 3 levers:

Size Increase (% growth on revenue)

Efficiency Increase (% improvement in profit margin)

Multiple Increase (% increase in EBITDA multiple)

7.1. SIZE LEVER

Inputs:

targetSizeGrowthRate (EA)


Revenue:

newRevenue = baseRevenue * (1 + EA)


Expenses:

newCOGS = baseCOGS * efficiency
newProfit = newRevenue - newExpenses
newAdjEBITDA = newProfit * margin


Value:

sizeAdjustedValue = newAdjEBITDA * multipleUsed
valueCreatedSize = sizeAdjustedValue - currentValue
valueCreatedSizePct = valueCreatedSize / currentValue

7.2. EFFICIENCY LEVER

Inputs:

targetEfficiencyImprovement (E)


Revenue remains constant.

Adjusted EBITDA:

newAdjEBITDA = baseEBITDA + (efficiencyGain)


Value:

effAdjustedValue = newAdjEBITDA * multipleUsed
valueCreatedEfficiency = effAdjustedValue - currentValue
valueCreatedEfficiencyPct = valueCreatedEfficiency / currentValue

7.3. MULTIPLE/RISK LEVER

Inputs:

targetMultipleIncrease (M)


Adjusted Multiple:

newMultiple = baseMultiple + (baseMultiple * M)


Value:

riskAdjustedValue = newMultiple * baseEBITDA
valueCreatedMultiple = riskAdjustedValue - currentValue
valueCreatedMultiplePct = valueCreatedMultiple / currentValue

8. PROBABILITY ANALYSIS (VALUATION DISTRIBUTION)

Excel distributes EBITDA multiples along standard deviation increments.

For each SD step:

multiple = meanMultiple + (stdDevStep * (stdDevRange/4))
mvicValue = EBITDA * multiple
probability = fixed probability (0.1, 0.2, etc.)


Sum probabilities = 1.

Aggregate Expected Value:

expectedValue = Σ (probability_i * mvicValue_i)

9. WEALTH GAP CALCULATOR

Inputs:

growthRate
profitMargin
multiple
yearsToExit
initialRevenue
initialEBITDA

Yearly revenue:
rev[0] = initialRevenue
rev[n] = rev[n-1] * (1 + growthRate)

Yearly EBITDA:
ebitda[n] = rev[n] * profitMargin

Yearly Value:
salePrice[n] = ebitda[n] * multiple

Years to reach target:

Excel:

yearsToExit = -1 * ( LN(target / current) / LN(1 / (1 + growthRate)) )
