QUICK START INSTRUCTIONS:
=========================

1. Prerequisites:
   - Docker Desktop installed (https://docker.com/products/docker-desktop)
   - Docker Compose installed

2. Start the application:
   Windows: double-click start-docker.bat
   macOS/Linux: ./start-docker.sh
   Or: docker-compose up --build

3. Access the app:
   Frontend: http://localhost:3000
   Backend API: http://localhost:5000/api

4. Stop the application:
   Press Ctrl+C or run: docker-compose down

ARCHITECTURE:
==============

Frontend (React + Nginx)
└─ Port 3000
   └─ Proxies /api requests to Backend

Backend (Node.js + Express)
└─ Port 5000
   └─ SQLite Database (persisted in Docker volume)

Both services run on a shared Docker network with automatic DNS resolution.

COMMON COMMANDS:
================

Start application:          docker-compose up --build
Start in background:        docker-compose up -d
View logs:                  docker-compose logs -f
Check service status:       docker-compose ps
Monitor resources:          docker stats
Stop services:              docker-compose down
Full cleanup:               docker-compose down -v
Rebuild images:             docker-compose build --no-cache
Restart services:           docker-compose restart

TROUBLESHOOTING:
================

Port 3000 in use?    Change in docker-compose.yml
Port 5000 in use?    Change in docker-compose.yml
Can't connect?       Check docker-compose logs -f
Services not ready?  Wait 10-15 seconds after startup
Need fresh start?    docker-compose down -v && docker-compose up --build

For detailed troubleshooting, see DOCKER.md or DOCKER_CHECKLIST.md
